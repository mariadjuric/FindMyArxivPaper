# Curated benchmark corpus seed list

This file is the human-edited starter list for the week-2 benchmark corpus.

Rules:
- `corpus.seed.csv` is authoritative for paper selection.
- The goal is not perfect coverage yet; the goal is a non-joke, on-topic, inspectable starter corpus.
- Prefer papers that are method-rich, explain concepts clearly, and can support chunk-level evidence annotation.
- Keep the three intended clusters visible:
  - galactic_dynamics
  - distribution_functions
  - action_angle_methods

Current policy:
- Use these seeds first.
- Backfill from heuristic matching only if a cluster is underspecified.
- In the next pass, replace this with a fully hand-checked paper subset and local PDFs/full text.
